# WatchBrief

WatchBriefは、気になる企業・人物・AI・技術などの公開情報を定期的に調査し、朝刊・夕刊のMarkdownレポートとして蓄積・閲覧する個人向けサイトです。

情報を集めるだけでなく、出典を残し、「確認できた事実」「AIによる整理」「今後の確認事項」を分けて読める状態を目指します。

> [!IMPORTANT]
> 現在は初期整備段階です。レポート生成、閲覧サイト、GitHub Actionsはまだ実装されていません。

## 何のためのものか

WatchBriefは、日々追いかけたい公開情報を朝刊・夕刊の形でまとめるための仕組みです。最終的には、定期実行された調査結果を日付別のMarkdownレポートとして保存し、静的サイトで閲覧できるようにします。

扱う情報は公開情報を前提にします。実際の保有銘柄、資産情報、個人的なウォッチ設定、APIキー、ログ、生成キャッシュはこのリポジトリでは管理しません。

## 想定している使い方

MVPでは、次の使い方を想定しています。

1. ウォッチ対象を設定する
2. 朝夕の定期実行または手動実行で公開情報を収集する
3. 引用付きMarkdownレポートを生成する
4. 日付別のレポート履歴として保存する
5. 静的サイトで読む

レポートでは、対象期間、収集日時、重要ポイント、対象別の新着、事実、AIによる整理、今後の確認事項、情報源、取得できなかった情報源を分けて残す予定です。

## 現在できること

まだ利用できるアプリケーションはありません。このリポジトリには、現時点では目的、公開範囲、開発・運用ルールだけを置いています。

実装方式、runtime、package manager、静的サイト生成ツールは未決定です。

## 公開上の注意

このリポジトリはPublicです。GitHub Pagesを有効化した場合、生成されたサイトも公開されます。

個人情報、APIキー、実際の資産情報、公開する意図のないウォッチ設定は含めないでください。
