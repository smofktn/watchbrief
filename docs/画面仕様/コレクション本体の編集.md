# コレクション本体の編集（Issue #74・設計中）

## 合意済みの範囲

作成済みの停止中Collectionの詳細から編集へ進み、名前・任意の調査方針・初回確認期間を保存して詳細へ戻る。一覧・再読み込みでも更新値を確認する。利用者向け仕様の正本は[プロダクト仕様](../product-definition.md#collection本体の編集issue-74)。入力条件は既存の[作成API](../API仕様/post-api-collections.md)を維持する。

別タブ等で先に保存されていた場合は、入力内容を残して保存を止める。最新の保存値と自分の入力を確認し、最新値を基に編集し直す。例えばタブAで名前を保存した後、古い名前の残るタブBから調査方針を保存しても、タブAの名前を上書きしない。自動統合は行わない。

## 未決定

編集URL、競合後に最新値を確認して編集し直す具体操作、更新API・版の表現・保存結果不明時の再試行契約は、続く設計相談で具体化する。上記の合意は実装・動作確認済みを意味しない。未保存変更確認は#42、配下設定CRUD等は親#18の残りとして維持する。
